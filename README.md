# Philonomosian Society Website

A redesigned website for Georgetown University's Philonomosian Society, developed by **Hoya Developers**.

## About

This project aims to replace the Society's existing Google Site with a modern, responsive, and interactive website. The new platform will improve access to Society information, events, and resources while making it easier for officers to manage and update content.

## Features

- Responsive design for desktop and mobile.
- Live events calendar integration.
- Interactive member and board directories.
- Society resolutions and historical records.
- Membership interest forms.
- Integration with existing Google Workspace tools.
